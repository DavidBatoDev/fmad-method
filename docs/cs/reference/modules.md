FMAD dodává dva moduly: `fmod-method` (kód `method`, skills pro doručování) a `fmod-core-tools` (kód `core-tools`, hub `fmad` a samostatné nástroje). Žádné oficiální doplňkové moduly neexistují.

:::tip[Instalace modulů]
Spusťte `npx skills add DavidBatoDev/fmad-method` a vyberte požadované skills včetně `fmad` a záznamů modulů `fmod-method` a `fmod-core-tools`. Poté požádejte skill `fmad`, aby spustil `fmad setup`.
:::

## Komunitní moduly

Vlastní modul si může napsat kdokoli: stačí složka `fmod-<kód>` se záznamem `fmod.toml`. Nápady a otázky můžete sdílet v [GitHub Discussions](https://github.com/DavidBatoDev/fmad-method/discussions).
