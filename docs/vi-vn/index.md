Foundry Method (FMAD — **F**oundry **M**ethod for **A**gile AI-Driven **D**evelopment) là một framework phát triển phần mềm dựa trên AI, giúp bạn xây dựng phần mềm xuyên suốt toàn bộ quy trình, từ hình thành ý tưởng và lập kế hoạch cho tới triển khai với agent. Framework này cung cấp các AI agent chuyên biệt, workflow có hướng dẫn, và khả năng lập kế hoạch thông minh thích ứng với độ phức tạp của dự án, dù bạn đang sửa một lỗi nhỏ hay xây dựng một nền tảng doanh nghiệp.

Nếu bạn đã quen làm việc với các trợ lý AI cho lập trình như Claude, Cursor, hoặc GitHub Copilot, bạn có thể bắt đầu ngay.

## Mở rộng và tùy chỉnh

Bạn muốn mở rộng FMAD bằng các agent, workflow, hoặc module của riêng mình? Bạn có thể tự viết skill hoặc module riêng (một thư mục `fmod-<code>` chứa bản ghi `fmod.toml`), dù bạn chỉ bổ sung khả năng mới cho FMAD hay xây dựng hẳn một module mới từ đầu. Để điều chỉnh các agent và workflow có sẵn, hãy dùng skill `fmad-customize` — xem [Tùy chỉnh FMAD](./how-to/customize-fmad.md).

## Bạn cần gì để bắt đầu

FMAD hoạt động với bất kỳ trợ lý AI cho lập trình nào hỗ trợ custom system prompt hoặc project context. Một số lựa chọn phổ biến:

- **[Claude Code](https://code.claude.com)** — Công cụ CLI của Anthropic (khuyến nghị)
- **[Cursor](https://cursor.sh)** — Trình soạn thảo mã lấy AI làm trung tâm
- **[Codex CLI](https://github.com/openai/codex)** — Agent lập trình trên terminal của OpenAI

Bạn nên quen với các khái niệm phát triển phần mềm cơ bản như quản lý phiên bản, cấu trúc dự án, và workflow Agile. Không cần có kinh nghiệm trước với các hệ thống agent kiểu FMAD, vì bộ tài liệu này được viết ra chính để hỗ trợ việc đó.
