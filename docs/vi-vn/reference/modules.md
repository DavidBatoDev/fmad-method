FMAD được mở rộng thông qua các module. FMAD phát hành đúng hai module chính thức, và bạn chọn skill của chúng trong quá trình cài đặt. Không có module bổ sung chính thức nào khác.

:::tip[Cài đặt module]
Chạy `npx skills add DavidBatoDev/fmad-method` rồi chọn những skill bạn muốn, bao gồm `fmad` và các bản ghi module `fmod-method` và `fmod-core-tools`. Sau đó yêu cầu skill `fmad` chạy `fmad setup`.
:::

## Foundry Method

Các skill delivery của FMAD, từ lập kế hoạch đến build, review và retrospective.

- **Mã:** `method`
- **Bản ghi module:** `fmod-method`

## Core Tools

Skill trung tâm `fmad` cùng các công cụ độc lập như brainstorming, party mode và tùy biến.

- **Mã:** `core-tools`
- **Bản ghi module:** `fmod-core-tools`

## Community Modules

Bất kỳ ai cũng có thể tự viết module của riêng mình: một bộ skill đi cùng nhau, cộng với một thư mục `fmod-<code>` chứa bản ghi `fmod.toml`. Xem [Cài đặt module tùy chỉnh](../how-to/install-custom-modules.md).
