`npx skills add DavidBatoDev/fmad-method`로 FMAD 스킬을 설치한 뒤 `fmad setup`을 실행하면 프로젝트에 FMAD를 설정하고 AI 코딩 도구와 연동할 수 있습니다. 나중에 업데이트할 때는 `fmad setup`을 다시 실행합니다.

## 사용 시점

- 새 프로젝트나 기존 프로젝트에 FMAD를 설치할 때
- 지원되는 AI 코딩 도구에 FMAD 스킬을 연결할 때
- 기존 FMAD 설치를 업데이트할 때
- 모듈을 추가·제거하거나 도구와 설치 설정을 변경할 때

:::note[필수 조건]

- 설치 프로그램을 실행하려면 **Node.js 20.12 이상**이 필요합니다.
- 설치된 스킬을 사용하려면 **지원되는 AI 코딩 도구**가 필요합니다.
- `fmad-build`, `fmad-build-auto`처럼 `uv`로 Python을 실행하거나 결과물을 렌더링하는 스킬에는 **uv**가 필요합니다. `uv`가 없어도 설치는 끝나지만 경고가 표시되며 설치하기 전까지 해당 스킬은 작동하지 않습니다.
- Skills CLI가 GitHub에서 스킬을 가져오려면 **Git**이 필요합니다.

:::

## FMAD 설치 및 확인

### 1. 대상 프로젝트 열기

터미널에서 FMAD를 설치할 프로젝트로 이동하세요. 다른 위치를 지정하지 않으면 현재 디렉터리에 설치됩니다.

### 2. 설치 프로그램 실행

```bash
npx skills add DavidBatoDev/fmad-method
```

화면의 안내에 따라 AI 코딩 도구와 스킬을 선택하세요. 설정과 도움말을 위한 `fmad`, 사용할 모듈의 레코드인 `fmod-method`와 `fmod-core-tools`를 포함하세요. 그런 다음 프로젝트 디렉터리에서 코딩 도구를 열고 `fmad` 스킬에 `fmad setup`을 실행해 달라고 요청하세요.

오류나 경고가 표시되면 함께 제시된 조치에 따르세요. `uv` 누락 경고는 설치를 중단하지 않지만 `uv`가 필요한 스킬은 설치하기 전까지 사용할 수 없습니다.

### 3. 완료 요약 확인

설치가 끝나면 `fmad setup`이 변경된 내용을 요약해 보여줍니다. 추가 조치가 필요한 경고도 함께 나옵니다.

### 4. 도구 연동 확인

프로젝트 디렉터리에서 선택한 AI 코딩 도구를 열고 `fmad-help` 스킬을 실행하세요. 다음에 무엇을 해야 하는지 물어보면 됩니다. 도구가 스킬을 인식해 실행한다면 연동이 끝난 것입니다.

## FMAD 업데이트 또는 재설정

### 1. 설치 프로그램 다시 실행

`_fmad` 디렉터리가 있는 프로젝트에서 `fmad` 스킬에 `fmad setup`을 다시 실행해 달라고 요청하세요. `fmad setup`은 각 모듈의 버전을 확인하고 새 버전이 있으면 `npx skills update`를 대신 실행해 줍니다. 스킬 선택을 바꾸려면 먼저 다음 명령을 실행하세요.

```bash
npx skills add DavidBatoDev/fmad-method
```

### 2. 감지된 경로 선택

설치 프로그램은 기존 설치를 감지하고 현재 상태에 맞는 업데이트 또는 수정 경로를 보여줍니다. 기존 설정을 새로 고치려면 업데이트를, 모듈·도구·설정을 바꾸려면 수정을 선택하세요. 이후 화면의 안내를 따르면 됩니다.

### 3. 업데이트된 연동 확인

완료 요약을 확인하고 필요하면 AI 코딩 도구를 다시 연 뒤 `fmad-help`를 실행하세요.

## 헤드리스 CI 설치

프롬프트 없이 설치하려면 설치할 스킬을 각각 `--skill`로 지정하고 `-y`를 추가해 확인 프롬프트를 건너뛰세요.

```bash
npx skills add DavidBatoDev/fmad-method --skill fmad --skill fmod-core-tools --skill fmod-method --skill fmad-build -y
```

그런 다음 `fmad` 스킬에 `fmad setup`을 실행해 달라고 요청하세요.

## 설치 결과

FMAD 스킬은 선택한 AI 도구가 사용하는 스킬 디렉터리에 설치됩니다. 프로젝트의 `_fmad` 디렉터리에는 스킬이 공통으로 사용하는 설정과 지원 스크립트가 저장됩니다. 설치가 끝나면 설정된 도구와 남아 있는 경고를 확인할 수 있습니다.
