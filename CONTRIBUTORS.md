## How Contributions Are Credited

- **Git history** — every contribution to FMAD is preserved in the commit history.
- **GitHub contributors graph** — see <https://github.com/DavidBatoDev/fmad-method/graphs/contributors>.

Anyone whose pull request is merged becomes a contributor. Bug reports, documentation fixes, and discussion all count.
