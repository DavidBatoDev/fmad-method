## What FMAD Changes

- **Name and branding.** The project is FMAD, "Foundry Method for Agile AI-Driven Development". Skill, module, folder, and identifier names changed with it: `bmad-*` became `fmad-*`, the `bmad` hub became `fmad`, module records `bmod-*` became `fmod-*` (with `fmod.toml`), and the project folders `_bmad/` and `_bmad-output/` became `_fmad/` and `_fmad-output/`.
- **Personas.** The named agents keep their upstream personalities under new names: Ember (analyst), Flint (product manager), Sienna (UX designer), Ferris (architect), Cinder (developer), and Blaze (brainstorming coach in the web bundles).
- **Distribution.** FMAD installs from `DavidBatoDev/fmad-method` through the Skills CLI and checks that repository for updates. The docs site is served from GitHub Pages. There is no npm installer and no plugin marketplace.
- **Scope.** References to the upstream community channels, sponsorship, ecosystem modules, and release history were removed. Legacy migration files from upstream releases were dropped. The versioning restarts at 1.0.0.
- **Assets.** The upstream logos, banner, and wordmarks were replaced with FMAD artwork.
